SERVER RULES

Respect the community. Keep the game fair.

01 // RESPECT

Treat players and staff respectfully. Harassment, hate speech and targeted abuse are not allowed.

02 // FAIR PLAY

No hacked clients, unfair modifications, exploiting bugs or abusing unintended mechanics.

03 // CHAT & CONTENT

No spam, advertising, impersonation or inappropriate content.

04 // STAFF DECISIONS

Follow staff instructions and use the appropriate contact channel if you want to appeal a punishment.

These are starter rules and may be expanded before the server launches.
