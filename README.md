# LEGACY_ERROR Website

Static website for GitHub Pages.

## Deploy
1. Create a public repository named `LegacyError.github.io` in the `LegacyError` GitHub account.
2. Upload the contents of this folder to the repository root (not the parent folder).
3. In Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.
4. The website will be published at `https://legacyerror.github.io/`.

The root `index.html` redirects to `/home/`. Server IP is intentionally shown as **COMING SOON**. Supported Minecraft versions are listed as **1.8 and above**, as provided.
